MUSEO MUSEUM WEBSITE

Files
- index.html: semantic page structure
- style.css: responsive layout, colours, typography and hover effects
- script.js: mobile menu and scroll reveal animation
- images/: the four supplied artwork assets

Run
Open index.html in a browser. An internet connection is needed to load the Inter font from Google Fonts.

Deploy
Upload the complete museo-museum folder to GitHub and enable GitHub Pages, or drag the folder into Netlify. Keep the images folder beside index.html.
